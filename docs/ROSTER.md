# Skill roster

Every skill in this repo (built or planned), its chokepoint, and its pack. This is the public list: no internal sources, no writer names, no paths. The validator also reads this file as its allowlist for `## Related skills` links, so a planned skill's name must appear here before any shipped skill links to it.

Chokepoints run in funnel order: Foundation, Offer, Attention, Leads, Appointments, Closed, Fulfillment, Retention, Referrals, Operate. The Clinic pack sits last.

## Foundation

| Skill | Chokepoint | Pack | Purpose |
|---|---|---|---|
| brand-voice | foundation | core | Build a written voice guide from the owner's own posts, emails and way of talking, so marketing sounds like them instead of an agency. |
| business-context | foundation | core | Set up and keep current the shared business context file every other skill reads first: what they sell, prices, best client, promise, voice, channels and numbers. |
| chokepoint-audit | foundation | core | Find which of the 8 chokepoints is actually stuck, so the owner fixes the real bottleneck instead of guessing. |
| messaging-compliance | foundation | core | One shared consent and compliance block for every skill that sends a text, call or automated DM: what the opt-in must say, quiet hours, opt-out handling, and registration basics. |
| proof-ledger | foundation | core | Record, check and clean up the results, numbers, testimonials, reviews and credentials the business is allowed to use as proof. |
