# GBP weekly post templates

Each post needs a real reason to exist. Pick the type that fits what's true this week.

## Offer post (only when the offer is real)

```
[Headline, under 58 characters]
[1-2 sentences: what it is, who it's for]
[Real expiration date if one exists]
[CTA button: Book, Call, Learn more]
```

## Tip post (tied to a real, recurring customer question)

```
[The question, in the customer's own words, as the headline]
[2-3 sentence answer, plain language]
[Optional: link to the full article if seo-article has covered it]
```

## Job/work photo post

```
[1 sentence: what the photo shows, specific, not "great work!"]
[Real photo from an actual job, with customer permission if they're visible]
```

## Seasonal/update post

```
[What's changing this season, specific to the business and climate]
[What the customer should do about it, if anything]
```

## Rules for every post

- Never invent a discount, a deadline, or a limited-quantity claim that isn't real.
- Use a real photo whenever the post references work; a stock photo on a "look at this job" post is a trust violation if discovered.
- Keep a running log of what's posted so the same tip doesn't repeat inside a few months.
