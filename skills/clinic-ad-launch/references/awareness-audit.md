# Awareness audit (Schwartz gate), clinic delta

Run **ad-creative-brief**'s `references/awareness-formats.md` for the full stage table, steps,
and gate. This file only adds what's different for a patient-facing practice.

## What's different

- "Problem aware" names the felt problem before the treatment is on the table: the workaround
  the patient does every day, the permission they feel they need, the decision they haven't been
  able to make. Never a universal symptom claim; it's their specific situation, not a diagnosis.
- "Solution aware" and "product aware" cells are offer-card statics that have already passed
  **health-claims-check**, not just the general copy gate.
- "Most aware" (retargeting) never shows a before/after, no matter how warm the audience; see
  **health-claims-check**'s Meta rule on that.
- The build sheet names which ad set each cell belongs to, and confirms no treatment name sits in
  that ad set's name or UTM (see **ad-launch**'s naming convention).

## Gate

Same as the core file: every stage has at least two cells.
